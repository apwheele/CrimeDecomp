# Overview

I want to write a paper about doing a STL type decomposition with monthly crime data in cities over time. The main motivation is to understand the major trends in different types of crime, and then to look at residual deviations across cities and crime types.

The type of model I want to use is a logit, I used it in this paper for homicide rates, but I want to use it for general crime patterns as well:

@article{wheeler2018monitoring,

That PDF is in this folder as well.


## Stat modeling

The model (in R code) for that paper is:

```
HomRanBin <- glmer(cbind(Homicide,Pop1 - Homicide) ~ (1|Year) + (1|ORI) + (1|Row), binomial, data=BigCit)
```

I want to use this same idea (aggregated logit binomial model), 

So this uses a discrete model for year and ORI effect. I want STL smooth for time period (year+month), a smooth term for year, and a seasonal term for months. Use splines to estimate these effects. (So seasonal should be a cyclical.) 

The `(1|Row)` is the overdispersion term in this equation, and essentially gets you the residuals in the STL type framework.

See the writing of Gavin Simpson on smoothing splines, https://fromthebottomoftheheap.net/. He has many excellent posts on this. So there should be a global smooth, and then compare others to the global, https://fromthebottomoftheheap.net/2017/10/11/difference-splines-i/, so I can look at deviations.

You can make modeling changes if you want (use mgcv or glmer), high level goal are:

 - I want to see overall trends, and be able to see city level deviations
 - I want to see them broken down by crime type (have a single big stacked model if possible)
 - I want to be able to filter out outliers by month and by curve
